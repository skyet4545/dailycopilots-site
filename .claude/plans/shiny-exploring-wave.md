# Devotional Copilot — Build Plan

## Context

Carlos wants a standalone SEO-optimized devotional site that captures organic search traffic for queries like "morning devotional for anxiety" and "Advent devotional for families." The site cross-promotes Bible Copilot (iOS) and builds an email list. The existing OpenAI/Rust content engine can generate all devotional content. This is the lowest-cost new product in the Copilot family.

## Architecture Decision

**Astro static site** in a new `devotional-copilot/` directory at the repo root.

Why Astro over Next.js: pure content site, zero JS by default (fastest possible pages), built-in markdown/MDX support, perfect Lighthouse scores out of the box, deploys to Netlify with zero config. No React runtime needed — just HTML + islands for the email form.

## Content Model (Markdown Frontmatter)

```yaml
---
title: "Finding Peace in Anxious Moments"
topic: "anxiety"           # maps to /topics/anxiety
season: null               # or "advent", "lent", "easter"
readTime: 5                # minutes
scripture: "Philippians 4:6-7"
date: "2026-04-03"
description: "A 5-minute morning devotional on releasing anxiety through prayer."
---
```

Body structure (each devotional):
1. **Opening Prayer** (2-3 sentences)
2. **Scripture Reading** (full text of the passage)
3. **Reflection** (the devotional message, ~400 words)
4. **Application** (1-2 practical steps for today)
5. **Closing Prayer**

## Content Generation Script

`scripts/generate-devotionals.ts` — calls OpenAI directly (same model as the Rust API: `gpt-4o-mini`) to batch-generate devotional markdown files.

**Initial content targets (50 devotionals):**
- 8 topics x 5 devotionals each = 40 topic devotionals
  - Topics: anxiety, grief, gratitude, forgiveness, faith, hope, patience, love
- 10 seasonal devotionals (Advent week 1-4, Lent week 1-4, Easter, Christmas)

## Email Signup

Simple form → Supabase `email_subscribers` table.

**New Supabase table:**
```sql
CREATE TABLE email_subscribers (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  email TEXT NOT NULL UNIQUE,
  name TEXT,
  source TEXT DEFAULT 'devotional-copilot',
  created_at TIMESTAMPTZ DEFAULT now()
);
ALTER TABLE email_subscribers ENABLE ROW LEVEL SECURITY;
-- Insert-only policy (anon can subscribe, nobody can read via API)
CREATE POLICY "Anyone can subscribe"
  ON email_subscribers FOR INSERT
  WITH CHECK (true);
```

The form posts to a small Supabase edge function or directly via the Supabase JS client (anon key, insert-only RLS).

## SEO Strategy

- **URL structure:** `/topics/anxiety`, `/seasons/advent`, `/devotional/finding-peace-in-anxious-moments`
- **Meta tags:** Unique title + description per page, OG image
- **Schema.org:** `Article` structured data on each devotional
- **Internal linking:** Topic pages link to all devotionals in that topic; each devotional links to related topics
- **Sitemap:** Auto-generated by Astro
- **Target keywords per topic page:**
  - "morning devotional for anxiety"
  - "daily devotional about grief"
  - "Advent devotional for families"
  - "Bible devotional on forgiveness"
