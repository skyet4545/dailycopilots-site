# v2.2 Bump Checklist — ASO creative + metadata ship

**Trigger:** run this AFTER v2.1.0 is approved & released (don't edit a version mid-review).
**Goal:** ship the optimized listing (metadata + screenshots) and set up the icon A/B.

## 0. Pre-flight
- [ ] Confirm v2.1.0 is `READY_FOR_SALE` (released).
- [ ] Build/deploy from **master**, never the worktree (per global rule).
- [ ] `git status` clean-ish before starting.
- [ ] Keyword Search Popularity validated in Apple Ads → final keyword string locked.

## 1. Version bump (single source of truth = project.yml)
- [ ] `project.yml`: `MARKETING_VERSION` → `2.2.0`, `CURRENT_PROJECT_VERSION` → next build #.
- [ ] `xcodegen generate`
- [ ] `plutil -replace CFBundleShortVersionString -string "2.2.0" BibleCopilot/Resources/Info.plist`
- [ ] `plutil -replace CFBundleVersion -string "<NNN>" BibleCopilot/Resources/Info.plist`
- [ ] Commit `project.yml` + `project.pbxproj` + `Info.plist` together.

## 2. Icon A/B prep (optional but recommended — needs a build)
- [ ] Add 1–2 alternate app icons to the asset catalog + `CFBundleAlternateIcons` (or asset-catalog alt icons) so PPO can test them.
- [ ] Keep the current compass as control.
- [ ] (If skipping icon test this round, leave as-is.)

## 3. Build → archive → upload
- [ ] `xcodebuild ... clean archive` → verify version + icon + branch before export.
- [ ] `xcodebuild -exportArchive` with ASC API key → upload.

## 4. Metadata push (after editable version exists)
- [ ] Create the v2.2 App Store version in ASC (or it's created on upload).
- [ ] `python3 marketing/asc_push_metadata.py`  (read-only — confirm diffs)
- [ ] `python3 marketing/asc_push_metadata.py --apply`
  - subtitle → `Verse Meaning & Bible Answers`
  - keywords → final validated string (default: `scripture,devotional,kjv,gospel,jesus,christian,chat,gpt,commentary,daily,reading,plan,prayer,niv`)
  - promo → the 7-day-trial line
- [ ] Set **What's New** text for v2.2.

## 5. Screenshots
- [ ] Replace default gallery with `marketing/screenshots/store-01…04.png` (6.9″) — OR keep current default and only run them via PPO (see step 7).

## 6. Submit
- [ ] PATCH localizations → POST reviewSubmission → set submitted=true.

## 7. Product Page Optimization (independent of the build)
- [ ] Run the screenshot A/B per `marketing/ppo-test-steps.md` (can start anytime, even before v2.2).
- [ ] After screenshot winner: run the **icon A/B** (requires step 2's alt icons shipped).
